# HTIX5288 触控板诊断记录（2026-11-19）

## 设备与驱动

- HID 设备：HTIX5288，VID 0x0911，PID 0x5288
- ACPI 节点：TPD0，连接 AMD I2C 控制器 AMDI0010
- 驱动版本：VoodooI2C 2.9.1、VoodooI2CHID 1.0、VoodooInput 1.1.7、VoodooGPIO 1.1、VoodooI2CServices 1.0
- Kernel Add 顺序已核实：VoodooGPIO → VoodooI2CServices → VoodooInput → VoodooI2C → VoodooI2CHID

## 当前观察

在 2026-11-19 本次干净启动后，hidutil list 能看到 VoodooI2CPrecisionTouchpadHIDEventDriver 和 VoodooI2CHIDDevice；IORegistry 中相关服务已 registered / matched / active，DeviceOpenedByEventSystem=Yes。

但 VID 0x0911 / PID 0x5288 对应的 IOHIDInterface 在采样时 DebugState 的 ReportAvailableCalls、ReportAvailableRuns、CreatedBuffers 均为 0。该采样发生在没有确认用户物理移动触控板之后，因此不能单凭这一帧计数判定重启后仍然损坏；必须由用户实际移动、点击并测试多指手势后再确认。

## 高度可疑但尚未在本机验证的上游修复

该 HID report descriptor 包含 Digitizer Usage 0x57（Surface Switch）与 0x58（Button Switch），二者是 Feature Report（功能报告）。上游 VoodooI2CHID 在 2026-11-09 合并 PR #82，加入进入 Precision Touchpad 模式后分别写入这两个开关的逻辑，防止某些触控板上电后默认关闭 surface / button reporting。

- PR：https://github.com/VoodooI2C/VoodooI2CHID/pull/82
- 合并提交：476c90ac42759beeec241bf5069ccd03c1dee39b

对当前 EFI 中的 VoodooI2CHID 二进制进行反汇编，尚未发现该 PR 的两个 Feature Report 写入。因此这是针对 HTIX5288 的合理候选修复方向，但 PR 测试设备并非本机 HTIX5288，不能把它写成已验证根因。

## 当前发布决定

本次公开 EFI 保留实机当前已启动的 VoodooI2CHID 1.0，不换入未完成构建或未经本机验证的 kext。等上游修复版本针对 HTIX5288 完成编译、加载和实际触控测试后，再单独发布驱动更新。
