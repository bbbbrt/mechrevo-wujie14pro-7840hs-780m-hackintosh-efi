# 2026-11-20 实机更新说明

## 本次更新

- 系统基准：macOS Tahoe 26.7.3（Build 25G342 / Darwin 25.6.0）。
- 显示输出：USB-C 一线连（DP Alt Mode）和 Type-C 转 HDMI 两种方式均已在本机实测可用。DP 直连记录为 2560×1440@60Hz，内屏 2880×1800@120Hz；HDMI 的精确分辨率/刷新率尚未记录。
- Intel AX200：更新 IntelBluetoothFirmware 2.5.2、BTLEAdvFixup 0.9.3、ForbiddenItlwm 0.6.0-beta.2；AirDrop（隔空投送）已在 26.7.3 实机验证可用。
- 公开配置：清理个人 SMBIOS 信息；使用前必须自行生成 Serial、MLB、SystemUUID 和 ROM。

## 重要取舍：26.7.3 与 NullArc

目前 26.7.3 是本机唯一已实测 AirDrop 可用的系统版本。但在该版本上，NullArc Radeon 780M 显示路径更容易触发降级保护。故障恢复期间可能出现 WindowServer 重启、短暂黑屏，严重时图形登录会话退出，用户需要重新登录。

因此：

- **AirDrop 优先**：可选择 macOS 26.7.3，但需要接受当前 NullArc 降级风险。
- **稳定性优先**：建议等待后续 NullArc 驱动更新或本项目进一步优化后再升级/切换；其他 macOS 版本的 AirDrop 状态尚未验证。
- 这属于当前实机观察，不代表所有设备都会出现相同频率的问题。后续 NullArc 上游升级或本项目优化有望改善。

## 尚未完成的验证

- 触控板输入报告、点击和多指手势完整回归。
- 睡眠、唤醒、合盖恢复。
- HDMI 精确分辨率/刷新率、长时间运行和热插拔。
- 不同 macOS 版本的 AirDrop 兼容性。

## 使用提醒

本仓库针对机械革命无界 14 Pro / Ryzen 7 7840HS / Radeon 780M。首次使用请先用 U 盘测试，备份原 EFI，并自行生成唯一 SMBIOS。不要直接覆盖唯一可启动的 EFI。
