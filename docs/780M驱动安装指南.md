# 机械革命无界 14 Pro (7840HS + 780M)
## macOS Tahoe 26.6.2 显卡硬件加速（Metal 3）安装激活指南

---

### 一、重要前置说明

1. **为什么现在系统很卡？**
   新安装的 macOS 默认运行在 CPU 软解（UEFI GOP 基础帧缓冲）模式下，780M 独显微码和 Metal 3 加速驱动（[NullArc](https://github.com/luuumi-dev/nullarc)）还没有在系统里激活，窗口移动和动画完全靠 CPU 渲染。
2. **安装后效果**：
   激活后，WindowServer 桌面合成由 **AMD Radeon 780M 接管**，全面支持 **Metal 3 硬件加速**，界面将极其丝滑流畅。

---

### 二、安装步骤（共 5 步）

#### 第一步：【必须先做】在系统设置中开启“自动登录”
> **原因**：由于当前 780M 驱动处于 Alpha 阶段，内屏开机时的用户密码登录界面（loginwindow）在 GPU 通道下容易出现黑屏鼠标。**开启自动登录后，系统开机直接绕过登录界面，直接进入桌面**，从而完美避开黑屏！

1. 点击屏幕左上角苹果图标 **** -> 打开 **系统设置 (System Settings)**。
2. 在左侧菜单点击 **用户与群组 (Users & Groups)**。
3. 找到 **自动以此身份登录 (Automatically log in as)**，选择你当前的用户名，并输入开机密码确认。

---

#### 第二步：解压 [NullArc](https://github.com/luuumi-dev/nullarc) 显卡驱动包
1. 在 U 盘（或本机 D 盘）中找到 `nullarc-0.3.0-alpha.zip`。
2. 把 `nullarc-0.3.0-alpha.zip` 复制到 **桌面 (Desktop)**。
3. 双击解压，解压后桌面上会有一个 `nullarc-0.3.0-alpha` 文件夹。

---

#### 第三步：检查内核驱动 `PhxBringup.kext` 是否已加载
打开 macOS 的 **终端 (Terminal)**（可在“启动台 -> 其他”中找到，或按 Command + 空格搜索 Terminal），复制并运行以下命令：

```bash
ioreg -l | grep phx-build
```

- **如果输出了一行类似 `"phx-build" = 20261021...`**：
  说明内核驱动已经成功加载！**直接跳到第四步**。

- **如果没有任何输出**：
  说明 EFI 中之前关闭了 `PhxBringup.kext`，需要在终端中挂载 EFI 并开启它：
  ```bash
  # 1. 查找 U 盘的 EFI 分区编号（例如 disk2s1）
  diskutil list
  
  # 2. 挂载该 EFI 分区（如果你的分区是 disk2s1，就填 disk2s1）
  sudo diskutil mount disk2s1
  
  # 3. 启用 PhxBringup.kext
  sudo plutil -replace Kernel.Add.16.Enabled -bool true /Volumes/EFI/EFI/OC/config.plist
  ```
  执行完毕后，重启电脑一次进入 macOS，再进行第四步。

---

#### 第四步：运行 [NullArc](https://github.com/luuumi-dev/nullarc) 驱动安装程序

在 macOS 终端中，依次运行以下命令：

1. **进入驱动目录**：
```bash
cd ~/Desktop/nullarc-0.3.0-alpha
```

2. **运行环境自检（只读检测，不修改任何文件）**：
```bash
sudo ./install.sh --check
```
输入开机密码（输入密码时光标不会动，输完直接按回车）。如果各项全部打勾 `✓`，说明环境完全合格！

3. **一键安装驱动并启用 GPU 桌面合成**：
```bash
sudo ./install.sh --windowserver
```
安装脚本会自动部署显卡微码固件、注入 `PhxAccel.kext`、部署 Metal 插件和 GPUBundles。

---

#### 第五步：重启并生效（需重启两次）

1. **第一次重启**：
   重启进入桌面后，后台守护进程会在 1~2 分钟内唤醒 GPU 并完成硬件校验。
2. **第二次重启**：
   再次重启电脑，系统桌面（WindowServer）将正式完全切换至 **AMD Radeon 780M** 渲染！

---

### 三、验证显卡驱动是否成功

进入桌面后，可以通过以下 3 点验证：
1. **直观体验**：拖动窗口、打开 Dock 栏和全屏动画极其丝滑流畅。
2. **关于本机**：点击左上角 ** -> 关于本机 (About This Mac)**，图形卡显示为 **AMD Radeon 780M**，且支持 **Metal 3**。
3. **查看驱动日志**：在终端运行：
   ```bash
   tail -n 20 /var/log/phxboot.log
   ```
   如果最后一行显示 `done`，说明 780M 硬件加速完全激活！

---

### 四、应急与着色器说明

- **首次微顿说明**：初次打开某些新特效（如首次打开启动台或控制中心毛玻璃效果）时，驱动需要编译一次着色器，可能会有 1~2 秒的一次性微顿，随后会自动缓存到本地，之后再次打开便不再卡顿。
- **安全回退保障**：[NullArc](https://github.com/luuumi-dev/nullarc) 内置了守护机制。如果发生连续卡死，系统会自动回退到 CPU 安全帧缓冲。如需手动关闭 GPU 加速，在终端运行 `sudo touch /Users/Shared/gpu/phxboot-off` 并重启即可。
